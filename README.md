# My Task Manager
# This application is a small task manager used to organize your tasks. Each task is color-coded based on its priority level. For instance, high priority tasks are red, medium priority tasks are yellow, and low priority tasks are light green. Once you are done with a task, you can press Complete, which will cross it out, or Delete, which will remove it from the task manager. You can add as many tasks as you would like. 

# Instructions:
# How to Run - Open the `index.html` file in a web browser.
# 1. Enter the task name into the task input box. 
# 2. Select the priority level of the task from the dropdown. The options are High, Medium, and Low. Then press Add Task to add your task to the task manager.
# 3. Once you are finished with the task, you can press Complete, which will strike through the task. If you would like to remove the task from the task manager, you can press Delete. 

# Known Problems or Incomplete Features
# Tasks are not saved after the page is refreshed or closed. The task manager only stores tasks while the page is open.
